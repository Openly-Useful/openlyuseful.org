Support

Use this page to find the right public channel for an Openly Useful website, project, skill, MCP server, package, or provider listing.

Publisher status

Openly Useful is the public brand. Openly Useful LLC is the planned legal entity, with status formation-pending. This support page does not represent that planned entity as formed or active.

General and publisher support

Email hello@openlyuseful.org with subject SUPPORT. Include the affected website, repository, package, provider, or listing; what you expected; what happened; and any safe reproduction details. Do not send passwords, API keys, access tokens, or unrelated personal information.

Project support

For an open-source project, use its GitHub issue tracker when the report can be public. Check the repository documentation first because project-specific support instructions take precedence. The Openly-Useful GitHub organization is the starting point for public repositories.

Security reports

Do not post vulnerabilities or sensitive security details in a public issue. Follow the security policy and email hello@openlyuseful.org with subject SECURITY, or use GitHub private vulnerability reporting where available.

Current service level

This is a public support route for the current informational sites and released public artifacts. It does not promise paid support, uptime, response-time guarantees, or a commercial service level. Any future product or marketplace support commitment will be published with the applicable offering after formation and publisher verification are complete.
