# Openly Useful Brand Templates

These evergreen templates extend the approved identity beyond social networks without creating new logo variants.

| Template | PNG use | SVG use |
|---|---|---|
| `openly-useful-presentation-cover-1920x1080` | Title slide, webinar holding slide, presentation thumbnail | Editable master for presentation-specific titles |
| `openly-useful-document-cover-letter-2550x3300` | US Letter press packet or report cover at 300 ppi | Editable master for report-specific titles |
| `openly-useful-email-signature-1200x240` | Insert at 600 × 120 CSS pixels for a two-times-density signature | Source master; avoid embedding SVG directly in email clients |

The templates intentionally contain only evergreen identity copy. Add a presentation or document title in the source generator; do not alter the embedded canonical logo group.

For email accessibility, include the sender’s name, role, URL, and contact details as live email text. Treat the image as decorative and use an empty alternative-text value where the client allows it.
