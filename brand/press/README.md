# Openly Useful Press Kit

Use these files when a partner, publication, event, or directory needs a transparent production logo.

| Context | PNG | Canonical vector source |
|---|---|---|
| Green institutional mark on light surfaces | `openly-useful-mark-primary-transparent-1024.png` | `../ou-monitor-mark-v3.svg` |
| Shell institutional mark on dark surfaces | `openly-useful-mark-reverse-transparent-1024.png` | `../ou-monitor-reverse-v3.svg` |
| Primary horizontal lockup on light surfaces | `openly-useful-lockup-primary-transparent-1600x289.png` | `../ou-lockup-horizontal-v4.svg` |
| Reverse horizontal lockup on dark surfaces | `openly-useful-lockup-reverse-transparent-1600x289.png` | `../ou-lockup-horizontal-reverse-v4.svg` |

The matching SVG files in this folder are exact-size transparent export canvases. Their embedded logo paths are copied directly from the canonical sources and validated by `scripts/validate_brand_exports.py`.
